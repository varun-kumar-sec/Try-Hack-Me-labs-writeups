## Technical Deep Dive: Diffie-Hellman Key Exchange
## Conceptual Mechanics
The Diffie-Hellman (DH) key exchange is an asymmetric cryptographic protocol designed to allow two parties to derive a shared secret key over an unencrypted network.
1. Public Parameters:
- $p$: A large prime modulus.
- $g$: A generator base.
2. Key Derivation Process:
- Party A selects private key $a$ and calculates public value $A = g^a \bmod p$.
- Party B selects private key $b$ and calculates public value $B = g^b \bmod p$.
- Shared secret is derived independently by both parties:$$S = (B)^a \bmod p = (A)^b \bmod p = g^{ab} \bmod p$$

## Mathematical Implementation in this Challenge
In standard deployments, private keys ($a$ and $b$) remain strictly confidential. In this challenge setup, the full parameter set ($p$, $g$, $a$, $b$, and $g^c$) was exposed in the HTML comment, allowing direct calculation of the derived key.
